# BIGTREETECH GTR giveaway (finished)

The new BIGTREETECH GTR bundle giveaway!

As promised, a new giveaway has started!

**5 happy winners** will each get a set of the new:

- [**BIGTREETECH GTR V1.0 32-bit board**](http://s.click.aliexpress.com/e/_d7rq4xE)
- [**BIGTREETECH M5 V1.0 expansion board**](http://s.click.aliexpress.com/e/_d7rq4xE)

![](../assets/img/posts/614fd8f1acab.png)

Most of us are already familiar with the fantastic **BIGTREETECH SKR** boards. I feel pretty comfortable saying that I really like this board. It offers many features for an affordable price:

- Fast 32-bit CPU
- 11 replaceable drivers with the M5 expansion board
- Efficient cooling
- Support for K-type thermocouple sensors
- Onboard Raspberry Pi connector
- Dedicated BLTouch/sensor/CAN/I2C connector
- USB socket
- And many more features

In short, another great board from BIGTREETECH.

**A huge thank you to BIGTREETECH for their generous contribution** 🙏
