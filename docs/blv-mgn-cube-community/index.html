BLV mgn Cube

3D Printer

Hi, my name is Ben Levi and This is BLV mgn Cube - an open-source 3D printer project. Building your own good and reliable 3D printer is the main purpose of this project. Basically, it's an open front structure CoreXY 3D printer, based on mgn linear rails for maximum accuracy, efficiency and high print quality.
